>Ubuntu 26.04 LTS 버전 이미지를 사용했습니다.

## 컨테이너 생성 및 실행
```bash
docker run \
--env=PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin \
--network=bridge \
--restart=no \
--hostname=[호스트이름] \
--name=[컨테이너이름] \
-p [현재컴퓨터포트]:[컨테이너포트번호] \
-v /[공유할폴더경로]:/[컨테이너안에서보여질폴더경로] \
-w /[접속시 시작디렉토리] \
-d ubuntu:latest \
sleep infinity
```
- 데스크탑 환경을 만들고 VNC를 이용해서 컨테이너 화면을 볼려면 포트 지정을 해야 합니다.
- bash가 꺼지지 않게 유지하기 위해서 잠시 `sleep infinity`를 넣어줬습니다.

## 터미널에서 bash로 컨테이너 열기
```bash
docker exec -it [컨테이너이름] bash
```

## 사용자 관련
### 사용자 추가, 로그인
```bash
useradd -m [사용자명]
su - [사용자명] -c "bash --login"
```
- `-m` 옵션: 사용자 홈 디렉토리를 `/home/[사용자명]`으로 자동 설정
- `su`: 유저 전환
- `su -`: 유저의 홈 디렉토리와 환경변수를 가져와서 새로운 쉘 환경 시작
### 사용자 비밀번호 설정 및 변경
```bash
passwd
```
### 컨테이너 사용자 로그인
```bash
docker exec -it [컨테이너이름] su - [사용자명] -s /bin/bash
```

## 한글 사용
```bash
apt-get install locales language-pack-ko
locale-gen ko_KR.utf8
```

```bash
dpkg-reconfigure locales
```
```bash
Locales to be generated: 177
Default locale for the system environment: 3
```
`ko_KR.UTF-8 UTF-8` 번호를 찾아서 입력
`ko_KR.UTF-8` 사용하기 위해 번호 3 입력


```bash
vim ~/.bashrc
```

>~/.bashrc
```vim
# Setting Language(ko_KR.UTF-8)
export LANGUAGE=ko_KR.UTF-8
export LANG=ko_KR.UTF-8
```
`~/.bashrc` 파일 수정 후 다시 bash를 키거나 `source ~/.bashrc` 명령어를 수행합니다.

```bash
apt install fonts-noto-cjk
```
마지막으로 폰트까지 설치해줍니다.

여기까지 했으면 터미널에서 한글 입력도 되고 깨지지 않는 한글 출력을 볼 수 있습니다.
