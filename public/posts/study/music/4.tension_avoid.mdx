# 텐션(tension)
- 기본 화성 위에 **긴장감**을 불러일으키는 **비화성음**을 쌓는 것
- 코드 톤에 따라서 **반음이 올라가거나 내려가거나** 할 수 있다.

# 어보이드(avoid)
- 불협화음을 일으키거나 코드의 기능을 변질시키는 음

---

# 코드 별 사용가능한 텐션

|            | ♭9  |  9  | #9  | 11  | #11 | ♭13 | 13  |
| ---------- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| **M7**     |     |  ✅  |     |     |  ✅  |     |  ✅  |
| **m7**     |     |  ✅  |     |  ✅  |     |     |  ✅  |
| **m7(♭5)** |     |  ✅  |     |  ✅  |     |  ✅  |     |
| **7**      |  ✅  |  ✅  |  ✅  |     |  ✅  |  ✅  |  ✅  |

# 텐션 해결
1. **9th → 1**
	- m7에서는 단2도가 생겨 울림이 좋지 않음
	- Major 7th -> 6th로 풀어주는 것이 좋음
2. **♭9th → 1, 9th → ♭9th → 1**
3. **♯9th → ♭9th → 1, ♯9th → 9th → ♭9th → 1** 
4. **11th → 3**
	- 11th는 sus4와 음이 같음
	- sus4 → 3
5. **♯11th → 5**
	- ♯11th는 텐션이라기보다는 ♭5
6. **13th → 5**
7. **♭13th → 5, 13th → ♭13th → 5**
